## Astryx
Main:
https://astryx.atmeta.com/

CLI:
https://astryx.atmeta.com/docs/cli

Purpose:
- agent-ready design system
- React 19+ / StyleX
- components
- themes
- templates
- CLI/agent documentation

Policy:
Use Astryx when its stack and design language fit the project.
Do not mix Astryx and shadcn arbitrarily on the same visual surface without a deliberate integration strategy.
