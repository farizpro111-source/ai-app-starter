# AI App Starter

Universal starter repository for building websites, dashboards, CRMs and web applications with ChatGPT/Codex.

## Core workflow
**Brief → Architecture → Design System → Implementation Plan → Build → Test**

Do not start coding before the brief, architecture, design system, and implementation plan are sufficiently defined.

## Principles
1. Reuse proven components and templates before creating new ones.
2. Prefer one coherent design system over ad-hoc styling.
3. Inspect actual library documentation/API before using a component.
4. Never call mocks, placeholders or unverified integrations “complete”.
5. Every meaningful feature must be run and tested.
6. Preserve working functionality when making local changes.
7. Use the smallest safe change that solves the requested problem.
8. Record important business rules in project documentation.
9. Use real browser verification for user-facing flows whenever possible.
10. Keep secrets out of Git.

## Starting a new project
1. Copy this repository into a new project repository.
2. Complete PROJECT-BRIEF.md.
3. Complete ARCHITECTURE.md.
4. Generate/approve DESIGN-SYSTEM.md.
5. Complete IMPLEMENTATION-PLAN.md.
6. Define acceptance criteria in TESTING.md.
7. Only then start implementation.

See docs/WORKFLOW.md.
